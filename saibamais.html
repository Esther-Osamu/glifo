Este projeto é um trabalho escolar para a SEPE do IFC Campus Araquari. O objetivo deste site é trazer reconhecimento para essa língua, aprofundar aprendizados a partir de interações e pesquisas. Utilizamos o Figma para fazer Wireframes e os layouts. Também usamos HTML5, CSS3 e JavaScript, editando os códigos no Visual Studio Code.
